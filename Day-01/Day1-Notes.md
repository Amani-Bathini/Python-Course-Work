What is Programming? 
Programming is the process of writing instructions that tell a computer what to do. Since computers understand only machine-level instructions, programming languages act as a bridge between humans and computers. A set of instructions written to perform a specific task is called a program. 
                  
                  -> Problem → Instructions → Program → Output

Programming Paradigms:
____________________________________

There are 2 main types:

A. Procedural Programming

* Focuses on Functions
* Executes step by step
* Best for small applications 

Example:
->Food Ordering:

1. Login()
2. Select Restaurant()
3. Select Food()
4. Payment()
5. Confirm Order()


 B. Object-Oriented Programming (OOP)

   Focuses on Objects and Classes that represent real-world entities. 

Exampl"
->Amazon Product
   Attributes:
      * Name
      * Price
      * Rating

   Methods
    * Add to Cart()
    * Buy Now()
    * Add Review()

Procedural vs OOP
____________________________________________

| Procedural      | OOP              |
| --------------- | ---------------- |
| Functions       | Objects          |
| Less Security   | High Security    |
| Low Reusability | High Reusability |
| Small Projects  | Large Projects   |
